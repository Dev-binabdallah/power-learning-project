# My First Python Program

This is my first Python program as PLP learner for week one assignment. It is a simple beginner project that displays personal information and my career goal.

## About the Project

The program uses Python variables to store and display:

- Full name
- Age
- Favourite language
- Career goal

## What I Learned

Through this project, I learned how to:

- Create and use variables
- Store text and numbers in variables
- Use the `print()` function
- Add comments using `#`
- Display multiple variables in one statement
